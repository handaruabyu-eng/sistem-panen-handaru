# Sistem Pencatatan Hasil Panen Digital

## Deskripsi Proyek

Proyek ini merupakan program Python sederhana untuk menghitung
total hasil panen berdasarkan jumlah hasil panen dan harga per kilogram.
Program ini juga memiliki fitur perhitungan diskon terhadap total hasil panen.

## Fitur Program

- Menghitung total hasil panen.
- Menghitung diskon.
- Menghitung total hasil panen setelah diskon.

## Cara Menjalankan Program

1. Pastikan Python telah terinstal pada komputer.
2. Unduh atau clone repository ini.
3. Buka terminal pada folder proyek.
4. Jalankan perintah berikut:

```bash
python panen.py
